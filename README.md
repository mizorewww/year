# year

One Codeforces solution per month — from January 1985 to December 2027.

- 516 commits, one per month, each dated on a random day (and time) of that month.
- Every problem was picked at random from the [Codeforces problemset](https://codeforces.com/problemset).
- The solutions are accepted **GNU C11 / GNU C** submissions downloaded from Codeforces,
  via the [open-r1/codeforces-submissions](https://huggingface.co/datasets/open-r1/codeforces-submissions) dataset.
- Each file header contains the problem link, rating, tags, and the source submission ID.

```
solutions/<year>/<MM-DD>_<contestId><index>_<slug>.c
```

The commit dates are backdated for fun — Codeforces itself started in 2010, so the 1985
part of this history is definitely fictional.

Generated on 2026-10-04 (compiled and checked with `cc -std=gnu11`).
